ABOUT / PROJECT SYSTEM

讓內容長大，
而不是每次重新開始.

這個專案將網站設計與內容寫作分開：以一份 AGENTS.md 描述規則，讓 AI 未來能沿用同樣的方式持續開發。

01 / PURPOSE

我們建立的是「可擴充的學習筆記系統」。

初始內容涵蓋人機互動、人工智慧及研究方法，使用者可以透過分類、搜尋和詳細文章頁快速閱讀。網站本身採用純 HTML、CSS、JavaScript，不需要額外框架或資料庫。

01 / CONSISTENCY

一致的呈現

統一的配色、字級、間距與內容欄位，讓每篇文章有一致的閱讀體驗。

02 / SEPARATION

內容與畫面分離

文章集中放在 data/notes.json，新增文章不必複製或改寫 HTML。

03 / REUSABILITY

可重複的流程

AI 依照 AGENTS.md 的欄位格式與檢查步驟，自動完成內容擴充。

02 / FILE STRUCTURE

從規則到網頁，
每個檔案都有明確責任。

設計、資料、程式、說明文件分別管理，避免因為新增一篇筆記而修改多個頁面。

● ● ●PROJECT STRUCTURE
interaction-notes/
├── AGENTS.md            # AI 開發規範
├── index.html           # 首頁
├── library.html         # 搜尋與篩選
├── note.html            # 共用文章模板
├── about.html           # 專案說明
├── data/
│   └── notes.json       # 所有筆記資料
└── assets/
    ├── css/style.css    # 視覺設計
    └── js/app.js        # 網站互動
03 / EXTEND THE PROJECT

以後新增一篇文章，
只需要三個步驟。

01

讓 AI 先閱讀 AGENTS.md

了解資料格式、分類代碼、檔名規則、排版方式與品質檢查原則。

02

在 notes.json 增加一筆內容

提供唯一 id、標題、分類、摘要、標籤與文章段落。不需要複製 HTML 或修改首頁。

03

測試後直接發布

確認 JSON 格式正確、分類正常、卡片可點擊、文章可閱讀，再將更新推送至 GitHub。
