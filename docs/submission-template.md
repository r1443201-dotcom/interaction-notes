## 繳交內容

**一、專案簡介**

本次專案主題為「交互筆記（Interaction Notes）」，建立一個以人機互動（HCI）、人工智慧（AI）與研究方法為主的線上學習筆記網站。網站包含首頁、全部筆記、文章詳細頁與專案說明頁，使用者可以透過分類篩選及關鍵字搜尋快速找到想閱讀的內容。

與先前只完成單一網頁的 Vibe Coding 不同，本次重點是建立可長期沿用的開發規範。因此我建立 `AGENTS.md`，規定網站設計風格、專案目錄、內容欄位、檔案命名、AI 新增資料的流程與完成後的驗證方式。網站採用 HTML、CSS、JavaScript 與 JSON，不需後端，方便部署至 GitHub Pages。

`AGENTS.md` 的主要內容包括：
1. 專案目的與技術限制：建立容易閱讀且可擴充的學習筆記系統。
2. 網頁風格與結構：統一導覽列、配色、字級、卡片樣式及響應式設計。
3. 內容資料規範：筆記必須有唯一 id、標題、分類、摘要、標籤、日期、閱讀時間與章節內容。
4. AI 開發與驗證流程：先閱讀規範，再編輯資料，完成後驗證格式、搜尋、篩選及文章頁是否正常。

**五、之後新增頁面或內容時，規則如何幫助 AI？**

當我希望新增一篇筆記時，AI 可以先閱讀 `AGENTS.md`，了解既有網站的架構及統一的資料格式，再直接把文章新增至 `data/notes.json`。因為首頁、文章列表與詳細文章都由同一份資料產生，所以不需要為每一篇文章重建 HTML，也不需要重新指定排版樣式。AI 只需確認新文章 id 不重複、分類正確、資料欄位齊全，再執行驗證並檢查畫面，即能沿用同一套規則持續擴充。

這樣不但降低每次重新溝通的成本，也能讓未來新增的內容維持一致性與可維護性。
